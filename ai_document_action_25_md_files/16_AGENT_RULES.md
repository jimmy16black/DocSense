# Coding Agent Rules

## Before Coding
Read the relevant docs, inspect the repository, check dependencies and identify the smallest safe change.

## While Coding
- Follow existing conventions.
- Do not invent contracts.
- Do not invent schema fields.
- Keep changes focused.
- Add tests.
- Do not expose secrets.
- Treat AI output as untrusted.

## Documentation
Before completion, update the relevant documentation and `17_PROJECT_STATUS.md`.

## Governance Protection
Agents may propose changes to foundational governance documents, but changes to security, retention, agent permissions, architecture, memory or release policies require explicit human approval.

## Completion
Return:

```text
IMPLEMENTED:
FILES:
TESTS:
VALIDATION:
RISKS:
DOCS_UPDATED:
FOLLOW-UP:
```
