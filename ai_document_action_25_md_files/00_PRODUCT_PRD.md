# Product Requirements Document

## Product
AI Document → Action

## Objective
Turn user documents into structured understanding, grounded answers, and useful actions.

## Core Loop
Upload → Validate → Process → Extract → Cite → Summarize → Ask → Act

## Supported Documents
- Insurance policies
- GST invoices
- Bills and receipts
- Rental/service contracts
- Other supported document types

## MVP
- Camera/PDF/gallery upload
- Async document processing
- Structured extraction
- Page/section citations
- Summary and alerts
- Grounded Q&A
- Document comparison
- Reminders/actions
- User authentication
- Subscription/usage controls

## Product Principles
1. Accuracy over fluency.
2. Evidence over unsupported inference.
3. Privacy by default.
4. Deterministic workflows where possible.
5. Agents are constrained by explicit tools and permissions.
6. Every consequential action requires appropriate user confirmation.
